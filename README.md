# רצף

עורך וידאו בדפדפן לעריכה ידנית של סרטונים קצרים (בערך עד 4 דקות) לפני העלאה ליוטיוב. אין שרת: המדיה, הפרויקט והייצוא נשארים במחשב.

הממשק בעברית וכיוונו מימין לשמאל. ציר הזמן עצמו נע משמאל לימין, כמו בעורכי וידאו. כתוביות בעברית מצוירות עם הגופן Heebo וכיוון RTL.

## הרצה מקומית

```bash
npm install
npm run dev
```

שרת הפיתוח עולה על [http://127.0.0.1:43123](http://127.0.0.1:43123).

```bash
npm test
npm run build
npm run preview
```

`npm run build` יוצר אתר סטטי בתיקייה `dist/`.

## מה יש בגרסה הזו

- ייבוא וידאו, שמע ותמונות מהמחשב, כולל גרירה לספרייה או ישר לציר. כפתור «טעינת מדיה לדוגמה» מכניס קבצים קצרים שמגיעים עם הפרויקט.
- ציר עם שני מסלולי וידאו, מסלולי טקסט (אפשר להוסיף ולהסיר), ושני מסלולי שמע. הזזה, קיצוץ, פיצול, מחיקה, מחיקה גולשת, הצמדה, וסמנים.
- נגן מסונכרן: ניגון והשהיה, גרירה על סרגל הזמן, זום, וקיצורים. חצים מזיזים את הקליפ הנבחר.
- כתוביות: גופנים בעברית (Heebo, Rubik, Assistant, Frank Ruhl), גודל, צבע, יישור, לוחית רקע, קו מתאר, צל, ואנימציית עמעום או החלקה. אפשר לגרור כתובית על התצוגה.
- מעברים בין קליפים צמודים באותו מסלול וידאו: קרוספייד, שקיעה לשחור, והחלקה.
- מהירות 0.25x–4x, זום ופאן מתחילה לסוף, ובהירות / ניגודיות / רווייה.
- עוצמה, נקודות עוצמה, הנמכת מוזיקה כשיש שמע אחר, עוצמת מאסטר, ופייד. גל על קליפי שמע ועל וידאו עם פס קול.
- שמירה אוטומטית ב-IndexedDB, קובץ `.retzef.json` בלי המדיה, וחבילת `.retzef.zip` שכוללת את הקבצים.
- ייצוא MP4: H.264 + AAC. פורמטים: 1080p30, 1080p60, 720p30, ו-Shorts 1080×1920. אם הדפדפן תומך ב-`showSaveFilePicker` הקובץ נכתב לדיסק תוך כדי הקידוד. אחרת הוא יורד בסוף. תמונת PNG של הפריים הנוכחי.

## למה WebCodecs ו-Mediabunny, ולא ffmpeg.wasm

ייצוא של כמה דקות ב-1080p צריך לקודד מאות מגה-בייט של וידאו. `ffmpeg.wasm` מריץ את FFmpeg ב-WebAssembly: הגרסה החד-חוטית איטית, והגרסה הרב-חוטית דורשת `SharedArrayBuffer` ולכן כותרות `Cross-Origin-Opener-Policy` ו-`Cross-Origin-Embedder-Policy` על השרת. זה מסבך פריסה סטטית, ועלול להיכשל בזיכרון על סרטון של כמה דקות.

[Mediabunny](https://mediabunny.dev/) מקודד דרך WebCodecs: פענוח וקידוד H.264/AAC בדפדפן, בדרך כלל עם האצה של המערכת, בלי כותרות מיוחדות. הפריימים מורכבים על canvas (וידאו, תמונות וכתוביות) ונכנסים ל-MP4. השמע ממוזג ב-Web Audio ואז מקודד ל-AAC. על כרום ועל אדג' ב-Windows וב-macOS נעשה שימוש במקודד ה-AAC של מערכת ההפעלה כשהוא זמין. בלינוקס, ובדפדפנים בלי AAC ב-WebCodecs, רצף טוען את `@mediabunny/aac-encoder`: מקודד AAC-LC ב-WebAssembly שמבוסס על המקודד של FFmpeg. הווידאו עדיין עובר ב-WebCodecs.

## פריסה

האתר סטטי. אחרי `npm run build` מעלים את `dist/` לכל מארח סטטי:

- Netlify או Cloudflare Pages: פקודת בנייה `npm run build`, תיקיית פרסום `dist`.
- GitHub Pages: אותו דבר. אם האתר לא בשורש הדומיין, מגדירים `base` ב-`vite.config.ts`.
- שרת מקומי: `npx serve dist`.

אין צורך ב-COOP/COEP. אין משתני סביבה.

## מגבלות

- הייצוא דורש Chrome או Edge, כי קידוד H.264 נשען על WebCodecs. AAC משתמש במקודד המערכת כשאפשר, ונופל למקודד WASM כשאין.
- בלי `showSaveFilePicker` (או אחרי ביטול חלון השמירה) הקובץ נאסף בזיכרון עד ההורדה. מעל 10 דקות הייצוא נחסם. שמירה לדיסק כותבת MP4 מקוטע (fMP4); יוטיוב מקבל אותו.
- קובץ ה-JSON לא כולל את המדיה. חבילת ה-zip כן.
- מהירות משנה גם את גובה הצליל. אין ייצוב pitch.
- מעבר פועל רק כששני קליפים נוגעים זה בזה. בזמן המעבר הפריים בקצה מוחזק, בלי ידית מדיה נוספת.
- ערבוב עברית ואנגלית באותה שורה תלוי ב-bidi של הקנבס בדפדפן.
